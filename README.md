# first-web-profile
**Primeiro perfil web introdutório.**

Aplicação web utilizando somente HTML e CSS para desenvolver uma página web estilizada.

## 02. Tecnologias Utilizadas
- HTML5
- CSS3

## 03. Como Instalar e Executar
Não é necessário instalar nenhuma dependência.

1. Clone este repositório:
   ```bash
   git clone https://github.com/di-fsantiago/web-first-profile.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd first-web-profile/atividade-css
   ```

3. Abra o arquivo `index.html` em seu navegador.

## 04. Exemplo de Uso ou Demonstração
A página apresenta um perfil pessoal e demonstra a utilização de:

- Estruturação de conteúdo com HTML;
- Estilização utilizando CSS externo;
- Cores, fontes e espaçamentos;
- Organização dos elementos da página;
- Formatação de textos.
